# Knowledge base C1: index of files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The engine indexes the files of the folders that the user adds: it parses 11 text formats in a child process, cuts the text into chunks, embeds the chunks with EmbeddingGemma 2, and stores them in SQLite. `forenote-cli index PATH` and `forenote-cli library` drive it.

**Architecture:** Migration v4 makes the KB tables again. A KB writer thread owns a second SQLite connection and runs each write in one transaction. A child process parses the files with a time limit and a memory limit. The index job is one scheduler job with the `INDEX` priority: it takes the pending documents one at a time and ends between files when a recording starts or a job with a higher priority waits. The scan runs at engine start and after `library.add_folder`.

**Tech Stack:** Python 3.11+ (the dev machine runs 3.13), asyncio, threads, a child process (`subprocess`), SQLite with FTS5 and sqlite-vec 0.1.9, LiteRT-LM (`litert-lm-api` 0.18.0), pypdf, python-docx, python-pptx, openpyxl, odfpy, striprtf, pytest.

**Spec:** `docs/superpowers/specs/2026-10-15-knowledge-base-chat-design.md` (sections 4, 5.1 to 5.6, 6, 7, 8, 9, 10, 11). **Carry-forward notes:** `docs/superpowers/notes/2026-10-12-carry-into-next-plans.md` (section "Knowledge base plan": "Database threading", "Embedding role", "Cache directory", "Settings", "Throughput").

**Plan C2** (the live watch, the other library methods, the meeting index) and **plan C3** (search and chat) come after this plan.

**Not in this plan:** a new vector for a chunk with another `embed_model` (spec C 5.1). C1 has only one embedding model, so plan C2 adds this check. The settings `kb_index_meetings` and `chat_source_tokens` come with plans C2 and C3. The move of `fts_query` to `kb/fts.py` comes with plan C3.

## Global Constraints

- Logs never contain user content: no path, no file name, no file text, no chunk. Log document ids, counts, durations, and error types only (spec C 8.2).
- The `documents.reason` column holds one code from this list only: `parse_error`, `parse_timeout`, `parse_crash`, `too_large`, `too_many_pages`, `encrypted`, `unsupported`, `unreadable`, `embed_failed`.
- Chunks: about 256 tokens, overlap of 32 tokens. No chunk is more than 320 real Gemma tokens. A chunk never joins two sections.
- The embedding vectors have 768 floats, normalized. The model accepts 1,024 tokens at most.
- The parser child process: 60 s for each file, 2 GB memory limit (`RLIMIT_AS`). It logs nothing.
- The KB connection: `busy_timeout = 5000`, `synchronous = NORMAL`. The loop connection keeps `synchronous = FULL`.
- Settings: `kb_max_file_mb` (default 50, range 1 to 500), `kb_max_pages` (default 500, range 1 to 5,000).
- The scan and the index ignore hidden files and folders, `~$*`, `*.swp`, `*.part`, `*.tmp`, `*.crdownload`, `.~lock.*#`, and unknown extensions. They do not follow symlinks.
- Pinned versions: `litert-lm-api==0.18.0`, `pypdf==6.19.0`, `python-docx==1.2.0`, `python-pptx==1.0.2`, `openpyxl==3.1.5`, `odfpy==1.4.1`, `striprtf==0.0.33`. Do not add PyMuPDF (AGPL).
- The engine import loads no parser library and no `litert_lm` (`tests/test_import_guard.py`).
- RPC changes are additive (protocol 1.x).

## Review Focus

These inputs are likely on a real computer, and no spec test names them. Each line has a test in the task that owns the code.

- **File names that are not valid UTF-8** (Linux allows any bytes). The scan must skip such a file, and it must not crash. Test: Task 9, `test_walk_skips_a_name_that_is_not_utf8`.
- **A file that the user cannot read** (mode `000`). The scan must mark it `error` with `unreadable`, and the other files must continue. Test: Task 9, `test_an_unreadable_file_gets_unreadable`.
- **Empty files and PDFs with no text layer** (scanned pages). They must become `indexed` with 0 chunks, and the next job must not parse them again. Test: Task 10, `test_a_file_with_no_text_is_indexed_with_no_chunks`.
- **Engine stop during a slow parse.** The stop must not wait for the 60 s parse limit. Test: Task 11, `test_engine_stop_during_a_slow_parse_is_fast`.
- **The same folder through a symlink or with a trailing slash.** It must be the same folder, not a second one. Test: Task 11, `test_the_same_folder_by_another_name_is_not_added_twice`.

- [ ] **Step 1: Write the migration**

Create `src/forenote/store/schema_v4.sql`:

```sql
-- Forenote schema v4: the knowledge base (spec C section 4.4).
-- No code used the v1 KB tables, so they are empty. Drop them and make them again.

DROP TRIGGER chunks_after_insert;
DROP TRIGGER chunks_after_delete;
DROP TRIGGER chunks_after_update;
DROP TABLE chunks_fts;
DROP TABLE chunks_vec;
DROP TABLE chunks;

CREATE TABLE chunks (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    document_id INTEGER REFERENCES documents(id) ON DELETE CASCADE,
    meeting_id  INTEGER REFERENCES meetings(id) ON DELETE CASCADE,
    kind        TEXT NOT NULL CHECK (kind IN ('file', 'transcript', 'notes')),
    position    INTEGER NOT NULL,      -- the order of the chunk in its source
    text        TEXT NOT NULL,
    locator     TEXT NOT NULL,         -- JSON: page, slide, sheet and rows, heading, time range, or notes part
    embed_model TEXT NOT NULL,         -- the manifest id of the model that made the vector
    CHECK ((document_id IS NULL) <> (meeting_id IS NULL)),
    CHECK ((kind = 'file') = (document_id IS NOT NULL))
);
CREATE INDEX chunks_document ON chunks(document_id, position);
CREATE INDEX chunks_meeting ON chunks(meeting_id, kind, position);

-- vec0 has no foreign key. Insert a chunk and its vector in one transaction.
-- The metadata column kind lets the search filter inside the KNN query.
CREATE VIRTUAL TABLE chunks_vec USING vec0(
    chunk_id  INTEGER PRIMARY KEY,
    embedding float[768] distance_metric=cosine,
    kind      text
);

```python
"""Data access for watched folders, documents, and chunks (spec C section 4.4).

LibraryStore never commits. The read methods work on any connection. Call
the write methods inside KbWriter.run(), which runs them in one transaction
on the KB connection (spec C 5.4).
"""

from __future__ import annotations

import json
import sqlite3
from dataclasses import dataclass, field
from typing import Any

import numpy as np

from forenote.store.jobs import now_iso

VECTOR_SIZE = 768  # the size of chunks_vec.embedding
DOC_STATUSES = ("indexed", "pending", "error", "skipped")


@dataclass(frozen=True)
class Folder:
    id: int
    path: str
    status: str


@dataclass(frozen=True)
class Document:
    id: int
    folder_id: int
    path: str
    mtime: float
    size: int
    sha256: str | None
    status: str
    reason: str | None


@dataclass(frozen=True)
class ChunkIn:
    """A chunk before it goes into the index."""

    position: int
    text: str
    locator: dict[str, Any] = field(default_factory=dict)


def _folder(row: sqlite3.Row) -> Folder:
    return Folder(row["id"], row["path"], row["status"])


def _document(row: sqlite3.Row) -> Document:
    return Document(
        row["id"], row["folder_id"], row["path"], row["mtime"], row["size"],
        row["sha256"], row["status"], row["reason"],
    )


class LibraryStore:
    def __init__(self, conn: sqlite3.Connection):
        self._conn = conn

    # Folders

    def add_folder(self, path: str) -> tuple[Folder, bool]:
        """Add a folder. Return the folder and True, or the existing folder and False."""
        cur = self._conn.execute("INSERT INTO folders(path) VALUES (?) ON CONFLICT(path) DO NOTHING", (path,))
        row = self._conn.execute("SELECT * FROM folders WHERE path = ?", (path,)).fetchone()
        return _folder(row), cur.rowcount == 1

    def folders(self) -> list[Folder]:
        return [_folder(r) for r in self._conn.execute("SELECT * FROM folders ORDER BY id")]

    def folder(self, folder_id: int) -> Folder | None:
        row = self._conn.execute("SELECT * FROM folders WHERE id = ?", (folder_id,)).fetchone()
        return _folder(row) if row else None

    def set_folder_status(self, folder_id: int, status: str) -> None:
        self._conn.execute("UPDATE folders SET status = ? WHERE id = ?", (status, folder_id))

    # Documents

    def documents(self, folder_id: int) -> dict[str, Document]:
        rows = self._conn.execute("SELECT * FROM documents WHERE folder_id = ?", (folder_id,))
        return {d.path: d for d in map(_document, rows)}

    def document(self, doc_id: int) -> Document | None:
        row = self._conn.execute("SELECT * FROM documents WHERE id = ?", (doc_id,)).fetchone()
        return _document(row) if row else None

    def put_document(
        self, folder_id: int, path: str, mtime: float, size: int, sha256: str | None,
        status: str = "pending", reason: str | None = None,
    ) -> int:
        """Insert or replace the row of a file. Return its id.

        A pending document keeps its old chunks until the index job replaces
        them. Another status removes the chunks.
        """
        self._conn.execute(
            "INSERT INTO documents(folder_id, path, mtime, size, sha256, status, reason) "
            "VALUES (?, ?, ?, ?, ?, ?, ?) "
            "ON CONFLICT(path) DO UPDATE SET folder_id = excluded.folder_id, mtime = excluded.mtime, "
            "size = excluded.size, sha256 = excluded.sha256, status = excluded.status, "
            "reason = excluded.reason, indexed_at = NULL",
            (folder_id, path, mtime, size, sha256, status, reason),
        )
        doc_id = self._conn.execute("SELECT id FROM documents WHERE path = ?", (path,)).fetchone()[0]
        if status != "pending":
            self._conn.execute("DELETE FROM chunks WHERE document_id = ?", (doc_id,))
        return doc_id

    def set_stat(self, doc_id: int, mtime: float, size: int) -> None:
        """The file has the same content and a new mtime or size."""
        self._conn.execute("UPDATE documents SET mtime = ?, size = ? WHERE id = ?", (mtime, size, doc_id))

    def mark(self, doc_id: int, status: str, reason: str) -> None:
        """Set error or skipped with a reason code, and remove the chunks."""
        if status not in ("error", "skipped"):
            raise ValueError(f"mark() takes error or skipped, not {status}")
        self._conn.execute(
            "UPDATE documents SET status = ?, reason = ?, indexed_at = NULL WHERE id = ?", (status, reason, doc_id)
        )
        self._conn.execute("DELETE FROM chunks WHERE document_id = ?", (doc_id,))

    def remove_document(self, doc_id: int) -> None:
        """The cascade removes the chunks. The triggers remove the FTS rows and the vectors."""
        self._conn.execute("DELETE FROM documents WHERE id = ?", (doc_id,))

    def next_pending(self, after_id: int = 0) -> Document | None:
        row = self._conn.execute(
            "SELECT * FROM documents WHERE status = 'pending' AND id > ? ORDER BY id LIMIT 1", (after_id,)
        ).fetchone()
        return _document(row) if row else None

    def pending_count(self, folder_id: int | None = None) -> int:
        if folder_id is None:
            return self._conn.execute("SELECT COUNT(*) FROM documents WHERE status = 'pending'").fetchone()[0]
        return self._conn.execute(
            "SELECT COUNT(*) FROM documents WHERE status = 'pending' AND folder_id = ?", (folder_id,)
        ).fetchone()[0]

    def counts(self, folder_id: int) -> dict[str, int]:
        counts = dict.fromkeys(DOC_STATUSES, 0)
        rows = self._conn.execute(
            "SELECT status, COUNT(*) FROM documents WHERE folder_id = ? GROUP BY status", (folder_id,)
        )
        for status, n in rows:
            counts[status] = n
        return counts

    # Chunks

    def replace_chunks(
        self, doc_id: int, sha256: str | None, chunks: list[ChunkIn], vectors: np.ndarray, embed_model: str
    ) -> bool:
        """Replace the chunks of a document and set it to indexed.

        Return False and write nothing when the document is gone or has
        another hash: a scan changed it while the index job read the file.
        """
        vectors = np.asarray(vectors, dtype=np.float32).reshape(-1, VECTOR_SIZE) if len(chunks) else np.zeros(
            (0, VECTOR_SIZE), np.float32
        )
        if vectors.shape != (len(chunks), VECTOR_SIZE):
            raise ValueError("replace_chunks() needs one vector for each chunk")
        cur = self._conn.execute(
            "UPDATE documents SET status = 'indexed', reason = NULL, indexed_at = ? WHERE id = ? AND sha256 IS ?",
            (now_iso(), doc_id, sha256),
        )
        if cur.rowcount == 0:
            return False
        self._conn.execute("DELETE FROM chunks WHERE document_id = ?", (doc_id,))
        for chunk, vector in zip(chunks, vectors):
            cur = self._conn.execute(
                "INSERT INTO chunks(document_id, kind, position, text, locator, embed_model) "
                "VALUES (?, 'file', ?, ?, ?, ?)",
                (doc_id, chunk.position, chunk.text, json.dumps(chunk.locator), embed_model),
            )
            self._conn.execute(
                "INSERT INTO chunks_vec(chunk_id, embedding, kind) VALUES (?, ?, 'file')",
                (cur.lastrowid, vector.tobytes()),
            )
        return True

    def chunk_texts(self, doc_id: int) -> list[str]:
        rows = self._conn.execute("SELECT text FROM chunks WHERE document_id = ? ORDER BY position", (doc_id,))
        return [r[0] for r in rows]
```

Note: `np.asarray(...).reshape(-1, VECTOR_SIZE)` turns a wrong vector count into a shape that the check refuses. A wrong vector size raises `ValueError` from `reshape` itself.

from __future__ import annotations

import hashlib
import re

import numpy as np

from forenote.embed.base import DIMENSION, EmbedError, Kind

_WORD = re.compile(r"\w+")


class FakeEmbedder:
    def __init__(self, model_id: str = "fake-embed", fail_on: str | None = None):
        self.model_id = model_id
        self.dimension = DIMENSION
        self.fail_on = fail_on
        self.calls: list[tuple[int, str]] = []
        self.loaded = False
        self.closed = False

    def load(self) -> None:
        self.loaded = True

    def embed_text(self, texts: list[str], kind: Kind) -> np.ndarray:
        if self.fail_on is not None and any(self.fail_on in t for t in texts):
            raise EmbedError("The fake embedder failed on a text.")
        self.calls.append((len(texts), kind))
        out = np.zeros((len(texts), self.dimension), np.float32)
        for i, text in enumerate(texts):
            for word in _WORD.findall(text.lower()):
                bucket = int.from_bytes(hashlib.blake2b(word.encode(), digest_size=4).digest(), "little")
                out[i, bucket % self.dimension] += 1.0
            norm = float(np.linalg.norm(out[i]))
            if norm == 0.0:
                out[i, 0] = 1.0
            else:
                out[i] /= norm
        return out

    def close(self) -> None:
        self.closed = True

```python
"""The LiteRT-LM backend for EmbeddingGemma 2 (decision 0001, spec C 5.1)."""

from __future__ import annotations

import threading
from pathlib import Path

import numpy as np

from forenote.embed.base import DIMENSION, EmbedError, Kind, with_prefix


class LiteRtEmbedder:
    """One native engine. A lock serializes the calls, so that any thread can call embed_text()."""

    def __init__(self, model_path: Path, model_id: str, cache_dir: Path, threads: int):
        self.model_id = model_id
        self.dimension = DIMENSION
        self._model_path = Path(model_path)
        self._cache_dir = Path(cache_dir)
        self._threads = threads
        self._lock = threading.Lock()
        self._engine = None
        self._options = None

    def load(self) -> None:
        import litert_lm  # import at call time: keep the engine import light

        litert_lm.set_min_log_severity(litert_lm.LogSeverity.ERROR)
        self._cache_dir.mkdir(parents=True, exist_ok=True)  # LiteRT-LM needs an existing directory
        with self._lock:
            self._engine = litert_lm.EmbeddingEngine(
                str(self._model_path),
                backend=litert_lm.Backend.CPU(thread_count=self._threads),
                cache_dir=str(self._cache_dir),
            )
            self._options = litert_lm.EmbeddingOptions(normalize=True)

    def embed_text(self, texts: list[str], kind: Kind) -> np.ndarray:
        if not texts:
            return np.zeros((0, self.dimension), np.float32)
        with self._lock:
            if self._engine is None:
                raise EmbedError("The embedding model is not loaded.")
            try:
                responses = self._engine.compute_embedding_batch(with_prefix(texts, kind), self._options)
            except RuntimeError:
                # The native message can name the input length. It has no text, but keep only a fixed message.
                raise EmbedError("The embedding model cannot embed a text.") from None
        out = np.asarray([r.embedding for r in responses], dtype=np.float32)
        if out.shape != (len(texts), self.dimension):
            raise EmbedError("The embedding model returned vectors of a wrong size.")
        return out

    def close(self) -> None:
        with self._lock:
            engine, self._engine = self._engine, None
        if engine is not None:
            engine.close()
```

```python
"""A token estimate for the chunk size (spec C 5.3).

The index job does not load the LLM, and LiteRT-LM has no tokenizer API.
The estimate counts each digit as one token (Gemma splits the digits), one
token for each 8 letters of a word, and one token for each 2 other
characters. Then it adds a margin. A models test checks the estimate
against the Gemma tokenizer.
"""

from __future__ import annotations

import math
import re

MARGIN = 1.15
_WORD = re.compile(r"\S+")


def word_cost(word: str) -> float:
    digits = letters = 0
    for c in word:
        if c.isdigit():
            digits += 1
        elif c.isalpha():
            letters += 1
    other = len(word) - digits - letters
    return MARGIN * (digits + math.ceil(letters / 8) + math.ceil(other / 2))


def estimate(text: str) -> int:
    return math.ceil(sum(word_cost(w) for w in _WORD.findall(text)))
```

Create `src/forenote/kb/chunker.py`:

```python
"""Sections to chunks of about 256 tokens with an overlap of 32 tokens (spec C 5.3)."""

from __future__ import annotations

import re
from collections.abc import Iterable

from forenote.kb.sections import Section
from forenote.kb.tokens import word_cost
from forenote.store.library import ChunkIn

CHUNK_TOKENS = 256
OVERLAP_TOKENS = 32
MAX_PIECE_CHARS = 200  # a longer run with no space is cut, so that each piece fits in a chunk

_PIECE = re.compile(r"(\S+)(\s*)")
_SENTENCE_END = re.compile(r"(?:[.!?;:]['\")\]]*\s*|\s*\n\s*)$")


def _pieces(text: str) -> list[str]:
    """Words with their trailing white space. The join of the pieces is the text without leading space."""
    out = []
    for word, space in _PIECE.findall(text):
        while len(word) > MAX_PIECE_CHARS:
            out.append(word[:MAX_PIECE_CHARS])
            word = word[MAX_PIECE_CHARS:]
        out.append(word + space)
    return out


def _sentence_end(pieces: list[str], costs: list[float], start: int, end: int, total: float, size: int) -> int:
    """Move the end back to a sentence end in the last quarter of the chunk, if there is one."""
    acc = total  # the tokens of pieces[start : j + 1]
    for j in range(end - 1, start, -1):
        if acc < 0.75 * size:
            break
        if _SENTENCE_END.search(pieces[j]):
            return j + 1
        acc -= costs[j]
    return end


def split_text(text: str, size: int = CHUNK_TOKENS, overlap: int = OVERLAP_TOKENS) -> list[str]:
    pieces = _pieces(text)
    costs = [word_cost(p.strip()) for p in pieces]
    chunks: list[str] = []
    start, n = 0, len(pieces)
    while start < n:
        end, total = start, 0.0
        while end < n and (end == start or total + costs[end] <= size):
            total += costs[end]
            end += 1
        if end < n:
            end = _sentence_end(pieces, costs, start, end, total, size)
        chunk = "".join(pieces[start:end]).strip()
        if chunk:
            chunks.append(chunk)
        if end >= n:
            break
        nxt, back = end, 0.0
        while nxt - 1 > start and back + costs[nxt - 1] <= overlap:  # always move forward
            nxt -= 1
            back += costs[nxt]
        start = nxt
    return chunks


def chunk_sections(sections: Iterable[Section]) -> list[ChunkIn]:
    """One or more chunks for each section. A chunk never joins two sections."""
    out: list[ChunkIn] = []
    for section in sections:
        for text in split_text(section.text):
            out.append(ChunkIn(len(out), text, dict(section.locator)))
    return out
```

```python
"""File parsers (spec C 4.2). Each parser returns a list of sections.

The parsers run in the parser child process (kb/parse_process.py). The
engine imports only EXTENSIONS from this module, so that the parser
libraries load in the child process only.
"""

from __future__ import annotations

import importlib
import warnings
from dataclasses import dataclass
from pathlib import Path

from forenote.kb.sections import Section

# The reason codes of documents.reason (spec C 4.4). Never put an exception text there.
CODES = (
    "parse_error", "parse_timeout", "parse_crash", "too_large", "too_many_pages",
    "encrypted", "unsupported", "unreadable", "embed_failed",
)
SKIP_CODES = frozenset({"too_large", "too_many_pages", "encrypted", "unsupported"})  # status skipped, not error


class ParseFailure(Exception):
    def __init__(self, code: str):
        if code not in CODES:
            raise ValueError(f"unknown reason code: {code}")
        super().__init__(code)
        self.code = code


@dataclass(frozen=True)
class Limits:
    max_pages: int = 500  # the kb_max_pages setting


# extension -> (module in this package, function)
_PARSERS = {
    ".txt": ("text", "parse_plain"),
    ".md": ("text", "parse_markdown"),
    ".markdown": ("text", "parse_markdown"),
    ".html": ("html", "parse_html"),
    ".htm": ("html", "parse_html"),
    ".rtf": ("rtf", "parse_rtf"),
    ".pdf": ("pdf", "parse_pdf"),
    ".docx": ("ooxml", "parse_docx"),
    ".pptx": ("ooxml", "parse_pptx"),
    ".xlsx": ("ooxml", "parse_xlsx"),
    ".odt": ("odf", "parse_odt"),
    ".odp": ("odf", "parse_odp"),
    ".ods": ("odf", "parse_ods"),
}
EXTENSIONS = frozenset(_PARSERS)


def parse(path: Path, limits: Limits) -> list[Section]:
    """Parse one file. Raise ParseFailure with a reason code, or MemoryError."""
    spec = _PARSERS.get(path.suffix.lower())
    if spec is None:
        raise ParseFailure("unsupported")
    try:
        with warnings.catch_warnings():
            warnings.simplefilter("ignore")  # the libraries warn about file content
            module = importlib.import_module(f"forenote.kb.parsers.{spec[0]}")
            sections = getattr(module, spec[1])(path, limits)
    except (ParseFailure, MemoryError):
        raise
    except OSError:
        raise ParseFailure("unreadable") from None
    except Exception:  # noqa: BLE001 - a broken file must not stop the other files
        raise ParseFailure("parse_error") from None
    out = []
    for s in sections:
        text = s.text.strip()
        if text:
            out.append(Section(text, s.locator))
    return out
```

"""Plain text and Markdown."""

from __future__ import annotations

import re
from pathlib import Path

from forenote.kb.sections import Section

_HEADING = re.compile(r"^(#{1,6})\s+(.*?)\s*#*\s*$")
_FENCE = ("```", "~~~")


def read_text(path: Path) -> str:
    """UTF-8 with replacement characters for bad bytes. A BOM is removed."""
    return path.read_bytes().decode("utf-8-sig", errors="replace")


def parse_plain(path: Path, limits) -> list[Section]:
    return [Section(read_text(path))]


def parse_markdown(path: Path, limits) -> list[Section]:
    sections: list[Section] = []
    heading: str | None = None
    buf: list[str] = []
    fenced = False

    def flush() -> None:
        text = "\n".join(buf).strip()
        if text:
            sections.append(Section(text, {"heading": heading} if heading else {}))
        buf.clear()

    for line in read_text(path).splitlines():
        if line.lstrip().startswith(_FENCE):
            fenced = not fenced
            buf.append(line)
            continue
        m = None if fenced else _HEADING.match(line)
        if m:
            flush()
            heading = m.group(2).strip() or heading
            buf.append(m.group(2).strip())
        else:
            buf.append(line)
    flush()
    return sections
```

"""HTML with the standard library parser. Each heading starts a section."""

from __future__ import annotations

from html.parser import HTMLParser
from pathlib import Path

from forenote.kb.parsers.text import read_text
from forenote.kb.sections import Section

_HEADINGS = {"h1", "h2", "h3", "h4", "h5", "h6"}
_SKIP = {"head", "script", "style", "noscript", "template", "svg"}
_BLOCK = {
    "p", "div", "br", "li", "tr", "td", "th", "section", "article", "header", "footer",
    "blockquote", "pre", "table", "ul", "ol", "dd", "dt", "hr", "main", "nav", "aside",
} | _HEADINGS


class _Collector(HTMLParser):
    def __init__(self) -> None:
        super().__init__(convert_charrefs=True)
        self.sections: list[Section] = []
        self._heading: str | None = None
        self._buf: list[str] = []
        self._skip = 0
        self._in_heading: str | None = None
        self._heading_text: list[str] = []

    def flush(self) -> None:
        lines = (" ".join(line.split()) for line in "".join(self._buf).splitlines())
        text = "\n".join(line for line in lines if line)
        if text:
            self.sections.append(Section(text, {"heading": self._heading} if self._heading else {}))
        self._buf.clear()

    def handle_starttag(self, tag: str, attrs) -> None:
        if tag in _SKIP:
            self._skip += 1
            return
        if self._skip:
            return
        if tag in _HEADINGS:
            self.flush()
            self._in_heading = tag
            self._heading_text = []
        if tag in _BLOCK:
            self._buf.append("\n")

    def handle_endtag(self, tag: str) -> None:
        if tag in _SKIP:
            self._skip = max(0, self._skip - 1)
            return
        if self._skip:
            return
        if tag == self._in_heading:
            heading = " ".join("".join(self._heading_text).split())
            self._heading = heading or self._heading
            self._buf.append(heading + "\n")
            self._in_heading = None
        if tag in _BLOCK:
            self._buf.append("\n")

    def handle_data(self, data: str) -> None:
        if self._skip:
            return
        if self._in_heading:
            self._heading_text.append(data)
        else:
            self._buf.append(data)


def parse_html(path: Path, limits) -> list[Section]:
    c = _Collector()
    c.feed(read_text(path))
    c.close()
    c.flush()
    return c.sections
```

```python
"""Spreadsheet rows to sections: one line for each row, tabs between the cells (spec C 5.3)."""

from __future__ import annotations

from collections.abc import Iterable
from typing import Any

from forenote.kb.sections import Section
from forenote.kb.tokens import estimate

# Below the chunk size, so that the chunker keeps each row group whole and the row range stays exact.
SHEET_SECTION_TOKENS = 200


def cell_text(value: Any) -> str:
    if value is None:
        return ""
    if isinstance(value, float) and value.is_integer():
        return str(int(value))
    return " ".join(str(value).split())


def row_text(values: Iterable[Any]) -> str:
    return "\t".join(cell_text(v) for v in values).rstrip("\t")


def sheet_sections(name: str, rows: Iterable[tuple[int, str]]) -> list[Section]:
    """Group the non-empty rows. The locator has the first and the last row number."""
    out: list[Section] = []
    buf: list[str] = []
    first = last = 0
    total = 0
    for number, text in rows:
        if not text.strip():
            continue
        cost = estimate(text)
        if buf and total + cost > SHEET_SECTION_TOKENS:
            out.append(Section("\n".join(buf), {"sheet": name, "rows": [first, last]}))
            buf, total = [], 0
        if not buf:
            first = number
        buf.append(text)
        last = number
        total += cost
    if buf:
        out.append(Section("\n".join(buf), {"sheet": name, "rows": [first, last]}))
    return out
```

"""PDF with pypdf. One section for each page with text."""

from __future__ import annotations

from pathlib import Path

from forenote.kb.parsers import Limits, ParseFailure
from forenote.kb.sections import Section


def parse_pdf(path: Path, limits: Limits) -> list[Section]:
    import pypdf

    reader = pypdf.PdfReader(str(path))
    if reader.is_encrypted:
        try:
            opened = reader.decrypt("")  # some PDFs have an empty user password
        except Exception:  # noqa: BLE001 - for example AES without the cryptography package
            opened = 0
        if not opened:
            raise ParseFailure("encrypted")
    if len(reader.pages) > limits.max_pages:
        raise ParseFailure("too_many_pages")
    out = []
    for number, page in enumerate(reader.pages, 1):
        text = page.extract_text() or ""
        if text.strip():
            out.append(Section(text, {"page": number}))
    return out

"""DOCX, PPTX, and XLSX."""

from __future__ import annotations

from pathlib import Path

from forenote.kb.parsers import Limits, ParseFailure
from forenote.kb.parsers.sheets import row_text, sheet_sections
from forenote.kb.sections import Section

_OLE = b"\xd0\xcf\x11\xe0\xa1\xb1\x1a\xe1"


def _check_container(path: Path) -> None:
    """An encrypted OOXML file is an OLE container, not a ZIP file."""
    with path.open("rb") as f:
        if f.read(8) == _OLE:
            raise ParseFailure("encrypted")


def parse_docx(path: Path, limits: Limits) -> list[Section]:
    _check_container(path)
    import docx

    document = docx.Document(str(path))
    sections: list[Section] = []
    heading: str | None = None
    buf: list[str] = []

    def flush() -> None:
        text = "\n".join(buf).strip()
        if text:
            sections.append(Section(text, {"heading": heading} if heading else {}))
        buf.clear()

    for block in document.iter_inner_content():
        if hasattr(block, "rows"):  # a table
            for row in block.rows:
                buf.append("\t".join(cell.text for cell in row.cells))
            continue
        style = block.style.name if block.style is not None else ""
        if style.startswith("Heading") or style == "Title":
            flush()
            heading = block.text.strip() or heading
        buf.append(block.text)
    flush()
    return sections


def _shape_texts(shape):
    from pptx.shapes.group import GroupShape

    if isinstance(shape, GroupShape):
        for inner in shape.shapes:
            yield from _shape_texts(inner)
        return
    if shape.has_text_frame:
        yield shape.text_frame.text
    if getattr(shape, "has_table", False) and shape.has_table:
        for row in shape.table.rows:
            yield "\t".join(cell.text for cell in row.cells)


def parse_pptx(path: Path, limits: Limits) -> list[Section]:
    _check_container(path)
    import pptx

    slides = list(pptx.Presentation(str(path)).slides)
    if len(slides) > limits.max_pages:
        raise ParseFailure("too_many_pages")
    out = []
    for number, slide in enumerate(slides, 1):
        parts = [t for shape in slide.shapes for t in _shape_texts(shape)]
        if slide.has_notes_slide:
            frame = slide.notes_slide.notes_text_frame
            if frame is not None:
                parts.append(frame.text)
        text = "\n".join(p for p in parts if p.strip())
        if text:
            out.append(Section(text, {"slide": number}))
    return out

from pathlib import Path

from forenote.kb.parsers import Limits, ParseFailure

def _load(path: Path):
    from odf.opendocument import load

    with zipfile.ZipFile(path) as z:  # BadZipFile: parse() turns it into parse_error
        manifest = z.read("META-INF/manifest.xml")
    if b"encryption-data" in manifest:
        raise ParseFailure("encrypted")
    return load(str(path))


def _name(node) -> str | None:
    qname = getattr(node, "qname", None)
    return qname[1] if qname else None


def _cells_text(row) -> str:
    from odf import teletype

    return "\t".join(teletype.extractText(c) for c in row.childNodes if _name(c) == "table-cell").rstrip("\t")


def parse_odt(path: Path, limits: Limits) -> list[Section]:
    from odf import teletype

    doc = _load(path)
    sections: list[Section] = []
    state = {"heading": None}
    buf: list[str] = []

    def flush() -> None:
        text = "\n".join(buf).strip()
        if text:
            sections.append(Section(text, {"heading": state["heading"]} if state["heading"] else {}))
        buf.clear()

    def walk(node) -> None:
        for child in node.childNodes:
            name = _name(child)
            if name == "h":
                text = teletype.extractText(child)
                flush()
                state["heading"] = text.strip() or state["heading"]
                buf.append(text)
            elif name == "p":
                buf.append(teletype.extractText(child))
            elif name == "table-row":
                buf.append(_cells_text(child))
            elif name is not None:
                walk(child)

    walk(doc.text)
    flush()
    return sections


def parse_odp(path: Path, limits: Limits) -> list[Section]:
    from odf import draw, teletype
    from odf import text as odtext

    pages = _load(path).presentation.getElementsByType(draw.Page)
    if len(pages) > limits.max_pages:
        raise ParseFailure("too_many_pages")
    out = []
    for number, page in enumerate(pages, 1):
        parts = [teletype.extractText(p) for p in page.getElementsByType(odtext.P)]
        text = "\n".join(p for p in parts if p.strip())
        if text:
            out.append(Section(text, {"slide": number}))
    return out

        def rows(t=t):

            for row in t.getElementsByType(table.TableRow):
                number += 1
                yield number, _cells_text(row)

    return out

```python
"""The parser child process (spec C 5.2).

A broken or hostile file can make a parser hang or use all the memory. A
thread cannot be stopped, but a process can. The engine sends one JSON line
for each file and reads one JSON line back. The child logs nothing, and it
returns only reason codes.
"""

from __future__ import annotations

import argparse
import contextlib
import json
import logging
import os
import resource
import select
import subprocess
import sys
import threading
import time
import warnings
from dataclasses import dataclass
from pathlib import Path

from forenote.kb.parsers import CODES
from forenote.kb.sections import Section

PARSE_TIMEOUT_S = 60.0
MEMORY_LIMIT = 2 * 1024**3


@dataclass(frozen=True)
class ParseResult:
    sections: list[Section] | None = None
    error: str | None = None  # a reason code


# The child side


def serve(parse_fn=None, inp=None, out=None) -> None:
    """Answer each request line with one answer line, until stdin closes."""
    from forenote.kb import parsers

    parse_fn = parse_fn or parsers.parse
    inp = inp or sys.stdin.buffer
    out = out or sys.stdout.buffer
    for line in inp:
        req = json.loads(line)
        try:
            sections = parse_fn(Path(req["path"]), parsers.Limits(int(req["max_pages"])))
            answer = {"sections": [{"text": s.text, "locator": s.locator} for s in sections]}
        except parsers.ParseFailure as e:
            answer = {"error": e.code}
        except MemoryError:
            answer = {"error": "parse_crash"}
        except Exception:  # noqa: BLE001 - never send an exception text: it can hold file content
            answer = {"error": "parse_error"}
        out.write(json.dumps(answer).encode() + b"\n")
        out.flush()


def main(argv: list[str] | None = None, parse_fn=None) -> None:
    ap = argparse.ArgumentParser(prog="forenote-parse")
    ap.add_argument("--memory-limit", type=int, default=MEMORY_LIMIT)
    args = ap.parse_args(argv)
    _, hard = resource.getrlimit(resource.RLIMIT_AS)
    resource.setrlimit(resource.RLIMIT_AS, (args.memory_limit, hard))
    logging.disable(logging.CRITICAL)
    warnings.simplefilter("ignore")
    serve(parse_fn)


# The parent side

_TIMEOUT = object()


class ParserProcess:
    """Call parse() from one thread at a time. close() can come from any thread."""

    def __init__(self, command: list[str] | None = None, timeout_s: float = PARSE_TIMEOUT_S,
                 memory_limit: int = MEMORY_LIMIT):
        self._command = command or [
            sys.executable, "-m", "forenote.kb.parse_process", "--memory-limit", str(memory_limit),
        ]
        self._timeout_s = timeout_s
        self._lock = threading.Lock()
        self._proc: subprocess.Popen | None = None
        self._buf = b""
        self._busy = False
        self._closed = False

    def parse(self, path: Path, max_pages: int) -> ParseResult:
        proc = self._start()
        if proc is None:
            return ParseResult(error="parse_crash")
        try:
            try:
                proc.stdin.write(json.dumps({"path": str(path), "max_pages": max_pages}).encode() + b"\n")
                proc.stdin.flush()
            except (OSError, ValueError):
                self._stop(proc)
                return ParseResult(error="parse_crash")
            line = self._read_line(proc, time.monotonic() + self._timeout_s)
            if line is _TIMEOUT:
                self._stop(proc)
                return ParseResult(error="parse_timeout")
            if line is None:
                self._stop(proc)
                return ParseResult(error="parse_crash")
            try:
                answer = json.loads(line)
                if "error" in answer:
                    return ParseResult(error=answer["error"] if answer["error"] in CODES else "parse_error")
                return ParseResult(sections=[Section(s["text"], s["locator"]) for s in answer["sections"]])
            except (ValueError, KeyError, TypeError):
                self._stop(proc)
                return ParseResult(error="parse_crash")
        finally:
            with self._lock:
                self._busy = False

    def close(self) -> None:
        with self._lock:
            self._closed = True
            proc, self._proc = self._proc, None
            busy = self._busy
        if proc is not None:
            self._kill(proc, close_pipes=not busy)  # a running parse() sees EOF and closes the pipes

    def _start(self) -> subprocess.Popen | None:
        with self._lock:
            if self._closed:
                return None
            if self._proc is None or self._proc.poll() is not None:
                if self._proc is not None:
                    self._kill(self._proc, close_pipes=True)
                self._buf = b""
                self._proc = subprocess.Popen(
                    self._command, stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                    stderr=subprocess.DEVNULL, bufsize=0,
                )
            self._busy = True
            return self._proc

    def _read_line(self, proc: subprocess.Popen, deadline: float):
        fd = proc.stdout.fileno()
        while b"\n" not in self._buf:
            left = deadline - time.monotonic()
            if left <= 0:
                return _TIMEOUT
            try:
                ready, _, _ = select.select([fd], [], [], left)
            except (OSError, ValueError):
                return None
            if not ready:
                return _TIMEOUT
            try:
                data = os.read(fd, 1 << 16)
            except OSError:
                return None
            if not data:
                return None
            self._buf += data
        line, _, self._buf = self._buf.partition(b"\n")
        return line

    def _stop(self, proc: subprocess.Popen) -> None:
        with self._lock:
            if self._proc is proc:
                self._proc = None
        self._kill(proc, close_pipes=True)

    @staticmethod
    def _kill(proc: subprocess.Popen, close_pipes: bool) -> None:
        with contextlib.suppress(OSError):
            proc.kill()
        with contextlib.suppress(subprocess.TimeoutExpired):
            proc.wait(5)
        if close_pipes:
            for pipe in (proc.stdin, proc.stdout):
                with contextlib.suppress(OSError):
                    pipe.close()


if __name__ == "__main__":
    main()
```

```python
"""The KB writer thread (spec C 5.4).

One thread owns a second SQLite connection. Each run() call is one
transaction. The event loop never waits for an fsync of an index write.
"""

from __future__ import annotations

import asyncio
import contextlib
import logging
import queue
import sqlite3
import threading
from collections.abc import Callable
from pathlib import Path
from typing import Any, TypeVar

from forenote.store.db import connect_kb

log = logging.getLogger(__name__)

T = TypeVar("T")
START_WAIT_S = 10.0


class KbWriterStopped(RuntimeError):
    """The KB writer does not run."""


def _resolve(fut: asyncio.Future, ok: bool, value: Any) -> None:
    if fut.done():
        return
    if ok:
        fut.set_result(value)
    else:
        fut.set_exception(value)


class KbWriter:
    def __init__(self, db_path: Path | str, connect_fn: Callable[[Path | str], sqlite3.Connection] = connect_kb):
        self._db_path = db_path
        self._connect = connect_fn
        self._queue: queue.Queue = queue.Queue()
        self._thread: threading.Thread | None = None
        self._running = False

    def start(self) -> None:
        ready = threading.Event()
        errors: list[BaseException] = []
        self._thread = threading.Thread(target=self._run, args=(ready, errors), daemon=True, name="forenote-kb-writer")
        self._thread.start()
        if not ready.wait(START_WAIT_S):
            raise KbWriterStopped("the KB writer did not start")
        if errors:
            raise errors[0]
        self._running = True

    def _run(self, ready: threading.Event, errors: list[BaseException]) -> None:
        try:
            conn = self._connect(self._db_path)
        except BaseException as e:  # noqa: BLE001 - start() raises it
            errors.append(e)
            ready.set()
            return
        ready.set()
        try:
            while (item := self._queue.get()) is not None:
                fn, loop, fut = item
                try:
                    with conn:  # commit on success, roll back on an error
                        value = fn(conn)
                except BaseException as e:  # noqa: BLE001 - hand every error to the caller
                    ok, value = False, e
                else:
                    ok = True
                with contextlib.suppress(RuntimeError):  # the loop can be closed already
                    loop.call_soon_threadsafe(_resolve, fut, ok, value)
        finally:
            conn.close()

    async def run(self, fn: Callable[[sqlite3.Connection], T]) -> T:
        if not self._running:
            raise KbWriterStopped("the KB writer does not run")
        loop = asyncio.get_running_loop()
        fut = loop.create_future()
        self._queue.put((fn, loop, fut))
        return await fut

    def stop(self, timeout: float = 10.0) -> bool:
        """Complete the queued calls, then end the thread. Blocking: call it from a worker thread."""
        if self._thread is None:
            return True
        self._running = False
        self._queue.put(None)
        self._thread.join(timeout)
        alive = self._thread.is_alive()
        if alive:
            log.warning("the KB writer did not stop within %s s", timeout)
        return not alive
```

```python
"""The folder scan (spec C 5.6): find the new, changed, and removed files of a folder."""

from __future__ import annotations

import fnmatch
import hashlib
import os
import stat
from dataclasses import dataclass, field
from pathlib import Path

from forenote.kb.parsers import EXTENSIONS
from forenote.kb.writer import KbWriter
from forenote.store.library import Document, Folder, LibraryStore
from forenote.workers import run_in_daemon_thread

TEMP_PATTERNS = ("~$*", "*.swp", "*.part", "*.tmp", "*.crdownload", ".~lock.*#")
HASH_BLOCK = 1 << 20


def ignored_name(name: str) -> bool:
    return name.startswith(".") or any(fnmatch.fnmatchcase(name, p) for p in TEMP_PATTERNS)


def _utf8(name: str) -> bool:
    """os.walk gives bad bytes as surrogates. Such a name cannot go into the database or a JSON line."""
    try:
        name.encode("utf-8")
    except UnicodeEncodeError:
        return False
    return True


@dataclass(frozen=True)
class FileStat:
    path: str
    mtime: float
    size: int


def walk(root: Path) -> list[FileStat]:
    """The supported regular files under root. No symlinks, no hidden or temporary files."""
    out = []
    for dirpath, dirnames, filenames in os.walk(root, followlinks=False):
        dirnames[:] = sorted(d for d in dirnames if not ignored_name(d) and _utf8(d))
        for name in sorted(filenames):
            if ignored_name(name) or not _utf8(name) or os.path.splitext(name)[1].lower() not in EXTENSIONS:
                continue
            full = os.path.join(dirpath, name)
            try:
                st = os.lstat(full)
            except OSError:
                continue  # the file went away
            if stat.S_ISREG(st.st_mode):
                out.append(FileStat(full, st.st_mtime, st.st_size))
    return out


def sha256_file(path: str | Path) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as f:
        while block := f.read(HASH_BLOCK):
            h.update(block)
    return h.hexdigest()


@dataclass
class ScanPlan:
    pending: list[tuple[FileStat, str]] = field(default_factory=list)  # new content, with its hash
    skipped: list[FileStat] = field(default_factory=list)  # too large
    unreadable: list[FileStat] = field(default_factory=list)
    stat_only: list[tuple[int, FileStat]] = field(default_factory=list)  # same content, new mtime or size
    removed: list[int] = field(default_factory=list)  # document ids


def plan_scan(root: Path, known: dict[str, Document], max_bytes: int, rehash: bool = False) -> ScanPlan:
    """Compare the files with the known documents. Blocking: run it in a worker thread."""
    plan = ScanPlan()
    known = dict(known)
    for f in walk(root):
        doc = known.pop(f.path, None)
        same_stat = doc is not None and doc.mtime == f.mtime and doc.size == f.size
        too_large_before = doc is not None and doc.reason == "too_large"
        if f.size > max_bytes:
            if not (same_stat and too_large_before):
                plan.skipped.append(f)
            continue
        if same_stat and not rehash and not too_large_before:
            continue
        try:
            sha = sha256_file(f.path)
        except OSError:
            plan.unreadable.append(f)
            continue
        if doc is not None and doc.sha256 == sha:
            if not same_stat:
                plan.stat_only.append((doc.id, f))
            continue
        plan.pending.append((f, sha))
    plan.removed = [d.id for d in known.values()]
    return plan


def apply_plan(store: LibraryStore, folder_id: int, plan: ScanPlan) -> int:
    """Write the plan. Run it in the KB thread. Return the pending count of the folder."""
    for f, sha in plan.pending:
        store.put_document(folder_id, f.path, f.mtime, f.size, sha)
    for f in plan.skipped:
        store.put_document(folder_id, f.path, f.mtime, f.size, None, "skipped", "too_large")
    for f in plan.unreadable:
        store.put_document(folder_id, f.path, f.mtime, f.size, None, "error", "unreadable")
    for doc_id, f in plan.stat_only:
        store.set_stat(doc_id, f.mtime, f.size)
    for doc_id in plan.removed:
        store.remove_document(doc_id)
    return store.pending_count(folder_id)


async def scan_folder(folder: Folder, library: LibraryStore, writer: KbWriter, max_bytes: int,
                      rehash: bool = False) -> int:
    """Scan one folder. A missing folder gets the status missing, and its documents stay (spec 10.2)."""
    root = Path(folder.path)
    if not root.is_dir():
        if folder.status != "missing":
            await writer.run(lambda c: LibraryStore(c).set_folder_status(folder.id, "missing"))
        return library.pending_count(folder.id)
    known = library.documents(folder.id)
    plan = await run_in_daemon_thread(lambda: plan_scan(root, known, max_bytes, rehash))

    def write(conn) -> int:
        store = LibraryStore(conn)
        if folder.status != "ok":
            store.set_folder_status(folder.id, "ok")
        return apply_plan(store, folder.id, plan)

    return await writer.run(write)
```

```python
"""The file index job (spec C 5.5): parse, chunk, embed, and write the pending documents."""

from __future__ import annotations

import logging
import time
from collections.abc import Awaitable, Callable
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

import numpy as np

from forenote.embed.base import DIMENSION, EmbedError, Embedder
from forenote.kb.chunker import chunk_sections
from forenote.kb.parse_process import ParseResult
from forenote.kb.parsers import SKIP_CODES
from forenote.kb.scan import sha256_file
from forenote.kb.writer import KbWriter
from forenote.scheduler import CancelToken, Report
from forenote.store.library import Document, LibraryStore
from forenote.workers import run_in_daemon_thread

log = logging.getLogger(__name__)

INDEX_JOB = "kb.index"
EMBED_BATCH = 8
REPORT_EVERY_S = 1.0  # spec C 5.5: progress at most one time each second


class KbError(RuntimeError):
    """An index job cannot run. The message is for the user and has no user content."""


class Parser(Protocol):
    def parse(self, path: Path, max_pages: int) -> ParseResult: ...


@dataclass
class IndexDeps:
    library: LibraryStore  # reads on the loop connection
    writer: KbWriter
    parser: Parser
    embedder: Callable[[], Awaitable[Embedder]]
    max_bytes: int
    max_pages: int
    should_yield: Callable[[], bool]  # a recording runs, or a job with a higher priority waits


@dataclass
class IndexResult:
    indexed: int = 0
    failed: int = 0
    skipped: int = 0
    removed: int = 0
    left: int = 0  # still pending: changed during the parse, or in a missing folder
    yielded: bool = False

    @property
    def progressed(self) -> bool:
        return self.indexed + self.failed + self.skipped + self.removed > 0


async def index_files(deps: IndexDeps, cancel: CancelToken, report: Report) -> IndexResult:
    """Index the pending documents one at a time, in id order. Each document gets one try in a job."""
    result = IndexResult()
    total = deps.library.pending_count()
    done = 0
    last_id = 0
    last_report = time.monotonic()
    embedder: Embedder | None = None
    while True:
        cancel.check()
        if deps.should_yield():
            result.yielded = True
            break
        doc = deps.library.next_pending(last_id)
        if doc is None:
            break
        last_id = doc.id
        if embedder is None:
            embedder = await deps.embedder()  # KbError: the job fails, the documents stay pending
        outcome = await _index_one(deps, embedder, doc, cancel)
        setattr(result, outcome, getattr(result, outcome) + 1)
        done += 1
        now = time.monotonic()
        if now - last_report >= REPORT_EVERY_S:
            last_report = now
            count = max(total, done)
            report(f"{done} of {count} files", done / count)
    log.info(
        "index job: %d indexed, %d failed, %d skipped, %d removed, %d left, yielded %s",
        result.indexed, result.failed, result.skipped, result.removed, result.left, result.yielded,
    )
    return result


async def _index_one(deps: IndexDeps, embedder: Embedder, doc: Document, cancel: CancelToken) -> str:
    """Return the name of the IndexResult counter for this document."""
    path = Path(doc.path)

    async def write(fn):
        return await deps.writer.run(lambda conn: fn(LibraryStore(conn)))

    try:
        st = path.stat()
    except FileNotFoundError:
        folder = deps.library.folder(doc.folder_id)
        if folder is None or not Path(folder.path).is_dir():
            return "left"  # the folder is missing: keep its documents (spec 10.2)
        await write(lambda s: s.remove_document(doc.id))
        return "removed"
    except OSError:
        await write(lambda s: s.mark(doc.id, "error", "unreadable"))
        return "failed"
    if st.st_size > deps.max_bytes:
        await write(lambda s: s.mark(doc.id, "skipped", "too_large"))
        return "skipped"

    parsed = await run_in_daemon_thread(lambda: deps.parser.parse(path, deps.max_pages))
    if parsed.error is not None:
        status = "skipped" if parsed.error in SKIP_CODES else "error"
        await write(lambda s: s.mark(doc.id, status, parsed.error))
        return "skipped" if status == "skipped" else "failed"

    try:
        sha = await run_in_daemon_thread(lambda: sha256_file(path))
    except OSError:
        await write(lambda s: s.mark(doc.id, "error", "unreadable"))
        return "failed"
    if sha != doc.sha256:
        # The file changed during the parse. Keep it pending with the new hash. A later job reads it again.
        await write(lambda s: s.put_document(doc.folder_id, doc.path, st.st_mtime, st.st_size, sha))
        return "left"

    chunks = chunk_sections(parsed.sections or [])
    parts = []
    try:
        for i in range(0, len(chunks), EMBED_BATCH):
            cancel.check()
            batch = [c.text for c in chunks[i : i + EMBED_BATCH]]
            parts.append(await run_in_daemon_thread(lambda b=batch: embedder.embed_text(b, "document")))
    except EmbedError:
        await write(lambda s: s.mark(doc.id, "error", "embed_failed"))
        return "failed"
    vectors = np.concatenate(parts) if parts else np.zeros((0, DIMENSION), np.float32)
    written = await write(lambda s: s.replace_chunks(doc.id, doc.sha256, chunks, vectors, embedder.model_id))
    return "indexed" if written else "left"
```

```python
"""RPC handlers for library.* methods (spec C 7.1), the folder scans, and the index jobs."""

from __future__ import annotations

import logging
import os
from pathlib import Path
from typing import Any

from forenote.embed.base import Embedder
from forenote.kb.indexer import INDEX_JOB, IndexDeps, KbError, index_files
from forenote.kb.scan import scan_folder
from forenote.models.manifest import model_for_tier
from forenote.rpc.protocol import APP_ERROR, RpcError
from forenote.scheduler import CancelToken, Priority, Report
from forenote.store.library import Folder, LibraryStore
from forenote.workers import run_in_daemon_thread

log = logging.getLogger(__name__)

MB = 1024 * 1024
EMBED_MISSING = "The embedding model is not downloaded. Run: forenote-cli models download."


def _inside(path: str, parent: str) -> bool:
    return os.path.commonpath([path, parent]) == parent


class LibraryHandlers:
    async def _library_add_folder(self, params: dict[str, Any]) -> dict[str, Any]:
        if self._closed:
            raise RpcError(APP_ERROR, "the engine is stopping")
        given = Path(params["path"])
        if not given.is_absolute():
            raise RpcError(APP_ERROR, "The folder path must be absolute.")
        try:
            path = str(given.resolve(strict=True))  # one name for the same folder: no symlink, no trailing slash
            path.encode("utf-8")
        except (OSError, RuntimeError, UnicodeEncodeError):
            raise RpcError(APP_ERROR, "No such folder.") from None
        if not os.path.isdir(path):
            raise RpcError(APP_ERROR, "No such folder.")
        for f in self.library.folders():
            if f.path != path and (_inside(path, f.path) or _inside(f.path, path)):
                raise RpcError(APP_ERROR, "The folder is inside a library folder, or it contains one.")
        folder, added = await self.kb_writer.run(lambda c: LibraryStore(c).add_folder(path))
        pending = await self._scan(folder)
        log.info("library folder %d %s; %d files pending", folder.id, "added" if added else "scanned", pending)
        return {"folder_id": folder.id, "added": added, "pending": pending, "job_id": self._kick_index()}

    async def _library_list(self, params: dict[str, Any]) -> list[dict[str, Any]]:
        return [
            {"id": f.id, "path": f.path, "status": f.status, "counts": self.library.counts(f.id)}
            for f in self.library.folders()
        ]

    # Scans

    async def _scan(self, folder: Folder, rehash: bool = False) -> int:
        max_bytes = self.settings.get("kb_max_file_mb") * MB
        return await scan_folder(folder, self.library, self.kb_writer, max_bytes, rehash)

    async def _scan_all(self) -> None:
        """The scan at engine start (spec C 5.6). Then index what is pending."""
        for folder in self.library.folders():
            if self._closed:
                return
            try:
                await self._scan(folder)
            except Exception as e:  # noqa: BLE001 - one folder must not stop the others
                log.error("the scan of folder %d failed: %s", folder.id, type(e).__name__)
        self._kick_index()

    # Index jobs

    def _kick_index(self) -> int | None:
        """Queue an index job when documents are pending and no index job is queued. Return its id."""
        if self._closed or self.scheduler is None:
            return None
        if self._index_job is not None:
            return self._index_job
        if self.library.pending_count() == 0:
            return None
        try:
            self._index_job = self.scheduler.submit(INDEX_JOB, Priority.INDEX, self._run_index)
        except RuntimeError:  # the scheduler stops
            return None
        return self._index_job

    async def _run_index(self, cancel: CancelToken, report: Report) -> None:
        self._index_again = False
        deps = IndexDeps(
            self.library, self.kb_writer, self.parser, self._kb_embedder,
            self.settings.get("kb_max_file_mb") * MB, self.settings.get("kb_max_pages"),
            self._index_should_yield,
        )
        result = await index_files(deps, cancel, report)
        self._index_again = result.yielded or result.progressed

    def _index_should_yield(self) -> bool:
        return self._recorder is not None or self.scheduler.has_waiting(Priority.INDEX)

    def _index_job_ended(self, job_id: int, status: str) -> None:
        if job_id != self._index_job:
            return
        self._index_job = None
        if status == "done" and self._index_again:
            self._kick_index()  # a yielded job continues later; the paused priority waits for the recording

    async def _kb_embedder(self) -> Embedder:
        """The loaded embedder. Load it at the first use and keep it (spec C 5.1)."""
        async with self._embed_lock:
            if self._embedder is not None:
                return self._embedder
            entry = model_for_tier(self.manifest, self.tier(), "embedding")
            if entry is None or not self.models.is_installed(entry):
                raise KbError(EMBED_MISSING)
            path = self.models.path(entry, entry.files[0])
            embedder = self.embedder_factory(path, entry.id, self.paths.cache_dir / "litert", self.hardware.threads)
            try:
                await run_in_daemon_thread(embedder.load)
            except Exception as e:  # noqa: BLE001 - out of memory, a broken file
                log.error("the embedding model cannot load: %s", type(e).__name__)
                raise KbError(f"The embedding model cannot load ({type(e).__name__}).") from None

```

```python
"""Embedding benchmark: chunks per second and PDF pages per minute (spec C 6.4)."""

from __future__ import annotations

import time
from dataclasses import dataclass
from pathlib import Path

from forenote.kb.chunker import CHUNK_TOKENS, OVERLAP_TOKENS, chunk_sections, split_text

PAGE_TOKENS = 500  # decision 0001: one page has about 500 tokens
SAMPLE = (
    "The team reviews the budget for the next quarter. The costs for hardware grow, and the plan moves two "
    "engineers to the new project in May. The meeting agrees to check the numbers again next week. "
)


@dataclass(frozen=True)
class EmbedBench:
    chunks: int
    chunks_per_s: float
    pages_per_min: float  # an estimate from the chunk speed
    pdf_pages: int | None = None
    pdf_pages_per_min: float | None = None  # measured: parse, chunk, and embed


def sample_chunks(n: int = 48) -> list[str]:
    return split_text(SAMPLE * (n * 8))[:n]  # the sample has about 60 tokens


def chunks_per_page() -> float:
    return PAGE_TOKENS / (CHUNK_TOKENS - OVERLAP_TOKENS)


def bench_embedder(embedder, chunks: list[str], batch: int = 8) -> float:
    embedder.embed_text(chunks[:1], "document")  # warm up
    start = time.perf_counter()
    for i in range(0, len(chunks), batch):
        embedder.embed_text(chunks[i : i + batch], "document")
    return len(chunks) / (time.perf_counter() - start)


def bench_pdf(embedder, parser, path: Path, max_pages: int = 5000) -> tuple[int, float]:
    """Parse, chunk, and embed one PDF. Return the last page with text, and the pages per minute."""
    start = time.perf_counter()
    result = parser.parse(path, max_pages)
    if result.error is not None:
        raise RuntimeError(f"The PDF cannot be parsed ({result.error}).")
    chunks = chunk_sections(result.sections or [])
    for i in range(0, len(chunks), 8):
        embedder.embed_text([c.text for c in chunks[i : i + 8]], "document")
    seconds = time.perf_counter() - start
    pages = max((s.locator.get("page", 0) for s in result.sections or []), default=0)
    return pages, 60 * pages / seconds if seconds > 0 else 0.0


def run_bench(embedder, parser=None, pdf: Path | None = None) -> EmbedBench:
    chunks = sample_chunks()
    cps = bench_embedder(embedder, chunks)
    pdf_pages = pdf_rate = None
    if pdf is not None:
        pdf_pages, pdf_rate = bench_pdf(embedder, parser, pdf)
        pdf_rate = round(pdf_rate, 1)
    return EmbedBench(len(chunks), round(cps, 2), round(60 * round(cps, 2) / chunks_per_page(), 1), pdf_pages, pdf_rate)
```

Note: `pages_per_min` uses the rounded `chunks_per_s`, so that the test can compute the same value.
