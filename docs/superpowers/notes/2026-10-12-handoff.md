## Machine setup

One command sets up a new machine (run it in a fresh clone):

    scripts/bootstrap-dev.sh --branch main --models-from OLDHOST --claude-from OLDHOST

`OLDHOST` is the old machine, reachable with ssh. Without `--models-from`, the
script downloads the models. The details:


- Linux x86_64 with AVX2, Python 3.11 or later, `uv`, CMake, and a C++
  compiler (`sudo apt install cmake g++`). `uv sync` builds llama-cpp-python
  from source (about 1 minute).
- Models go to `~/.local/share/forenote/models`. Copy that directory from the
  old machine, or download again: `uv run forenote-cli models download` for
  the tier of the machine. The spike and the model tests also need
  `gemma-4-e2b-q4_0` (3.35 GB). The download checks the SHA-256.
- Run `uv run pytest -q -W error` (no models), `-m models` (needs the
  models), and `-m audio` (needs PipeWire or PulseAudio).
