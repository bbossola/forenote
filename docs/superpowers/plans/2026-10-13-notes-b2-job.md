# Notes B2: Notes Job, Engine Wiring, RPC and CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After a meeting, the engine writes enhanced notes with the local LLM: an expansion for each bullet, a summary, and action items. Clients add bullets, read the notes, and run the job again through RPC and the CLI.

**Architecture:** Task 1 makes the llama.cpp backend safe to keep loaded in the engine (abort callback, safe `close()`). `forenote/notes/` holds pure helpers (`context.py`, `search.py`, `prompts.py`) and the job (`enhance.py`). The job runs in the scheduler with the priority NOTES. The engine loads one LLM instance at the first notes job and keeps it. After a recording with transcript lines, the meeting status becomes `processing`, and the engine queues the notes job. `engine/handlers/notes.py` serves the `notes.*` methods. The CLI gets bullet input in `record`, and the commands `note`, `notes`, and `enhance`.

**Tech Stack:** Python 3.11+ (tests run on 3.13), asyncio, threads, llama-cpp-python 0.3.36, SQLite FTS5, jsonschema, pytest.

**Spec:** `docs/superpowers/specs/2026-10-12-notes-enhancement-design.md` (sections 3, 4, 5.1 to 5.4, 5.6, 7, 8, 10.1 to 10.3). **Decision:** `docs/decisions/0003-llm-runtime.md`. **Carry-forward notes:** `docs/superpowers/notes/2026-10-12-carry-into-next-plans.md` (sections "All plans", "Plan B2: LLM instance lifecycle", "Plan B2: decisions from the PR #3 review").

**Scope split (owner decision, 2026-10-13):** Plan B3 comes after this plan. It covers the live reading (spec section 5.5, with the prefill-only method and the thread change), the quality fixtures and the integration tests (spec 10.4, 10.5), `bench llm`, and the speed target (spec 6.4). - Context size per tier: low 8,192, default 16,384, high 32,768 (spec 6.1).
- Prefix mode: the prefix fits when its token count is no more than the context size minus 2,048 (spec 5.3).
- `max_tokens`: bullet 200, summary 500, action items 500, map chunk 300. Temperature 0.2 for all steps (spec 5.3, 5.4).
- Time window of a bullet: `t_written_ms - 3 min` to `t_written_ms + 1 min`. The keyword search returns the times of up to 5 lines (spec 5.3).
- Map-reduce chunks: about 3,000 tokens, cut at line boundaries. The bullet prompt of map-reduce holds up to about 1,500 tokens of transcript lines (spec 5.4).
- RPC limits: bullet text 1 to 500 characters, `update_bullets` 0 to 200 items, `update_enhanced` text 0 to 2,000 characters (spec 7.1).
- `notes.enhance` error texts, exactly: "The meeting is still recording.", "The notes are already in progress.", "The language model is not downloaded. Run: forenote-cli models download.", "The meeting has no transcript.", "No such meeting.", "No such bullet." (spec 7.1).
- The protocol stays 1.x. All schema changes are additive.
- The original bullet text never changes because of the LLM. The job never overwrites an edited expansion unless the call has `force: true` (spec 5.6).
- The import of `llama_cpp` happens only when the engine loads the model. `tests/test_import_guard.py` must keep passing.

This task handles the carry-forward section "Plan B2: LLM instance lifecycle", except the prefill-only method and the thread change (plan B3).

**Files:**
- Modify: `src/forenote/llm/llamacpp.py`
- Modify: `tests/llm/test_llamacpp.py`, `tests/llm/test_llamacpp_model.py`, `tests/llm/test_base.py`
- Modify: `tests/conftest.py`, `tests/asr/test_ami_quality.py`, `tests/asr/test_transcriber.py` (fixture rename)

**Interfaces:**
- Consumes: `forenote.llm.base` (`GenParams`, `LlmError`, `PromptTooLong`), `forenote.scheduler.CancelToken`.
- Produces: `LlamaCppGenerator(model_path, model_id, context_size, threads)` with `load()`, `close()`, `loaded`, `render()`, `count_tokens()`, `generate()`. New behavior: a cancel, a stall, or `close()` aborts a running prompt read within one compute step. `close()` is safe while a generation or a `count_tokens()` runs. The conftest fixture `speech_model_dir` becomes `model_dir`.

**Design:**
- `load()` registers one abort callback for the context: `llama_cpp.llama_set_abort_callback(llm._ctx.ctx, self._abort_cb, None)`. `self._abort_cb = llama_cpp.ggml_abort_callback(self._should_abort)`. Keep the reference on `self`.
- `_should_abort()` returns `True` when the generator closes (`self._closing.is_set()`), or when the stop event of the running generation is set (`self._current_stop`). The worker sets `self._current_stop = stop` after it takes `self._lock`, and sets it back to `None` before it releases the lock. A late `stop.set()` of an earlier generation therefore never aborts a later one.
- When the stop event is set or the generator closes, an exception from `create_completion` (the abort raises `RuntimeError`) is not an error of the caller. The worker ends quietly after a stop. After a close, it reports `LlmError("the model is closed")`.
- A second lock, `self._model_lock`, protects the model object itself. `count_tokens()` and `close()` take it. A generation does not take it, because `tokenize` and `decode` can run at the same time. `count_tokens()` therefore never waits for a generation.
- `close()`: set `self._closing`, take `self._lock` (the abort callback makes the worker release it quickly), take `self._model_lock`, close the model, and clear `_llm`, `_formatter` and `_grammar_type`. After `close()`, `render()` raises `LlmError` (carry item "render() after close()"). A later `load()` clears `self._closing`.

```python
class LlamaCppGenerator:
    """One loaded GGUF model. Only one generation uses the model at a time.

    load() and close() block. Call them in a worker thread. A cancel, a stall,
    or close() stops a running prompt read through the abort callback of llama.cpp.
    """

    def __init__(self, model_path: Path, model_id: str, context_size: int, threads: int):
        self.model_path = model_path
        self.model_id = model_id
        self.context_size = context_size
        self.threads = threads
        self._llm: Any = None
        self._formatter: Any = None
        self._grammar_type: Any = None
        self._lock = threading.Lock()  # one generation at a time
        self._model_lock = threading.Lock()  # the model object: close() against count_tokens()
        self._closing = threading.Event()
        self._current_stop: threading.Event | None = None
        self._abort_cb: Any = None  # keep the ctypes callback alive

    @property
    def loaded(self) -> bool:
        return self._llm is not None

    def _should_abort(self, _data: Any = None) -> bool:
        stop = self._current_stop
        return self._closing.is_set() or (stop is not None and stop.is_set())

    def load(self) -> None:
        if self._llm is not None:
            raise LlmError("the model is loaded already")
        import llama_cpp
        from llama_cpp.llama_chat_format import Jinja2ChatFormatter

        self._closing.clear()
        llm = llama_cpp.Llama(
            model_path=str(self.model_path),
            n_ctx=self.context_size,
            n_threads=self.threads,
            n_threads_batch=self.threads,
            n_batch=512,
            flash_attn=True,  # decision 0003: faster, less memory
            swa_full=False,  # decision 0003: the prefix reuse still works
            verbose=False,
        )
        try:
            template = llm.metadata.get("tokenizer.chat_template")
            if not template:
                raise LlmError("the model has no chat template")
            formatter = Jinja2ChatFormatter(
                template=template,
                eos_token=llm._model.token_get_text(llm.token_eos()),
                bos_token=llm._model.token_get_text(llm.token_bos()),
            )
            abort_cb = llama_cpp.ggml_abort_callback(self._should_abort)
            llama_cpp.llama_set_abort_callback(llm._ctx.ctx, abort_cb, None)
            grammar_type = llama_cpp.LlamaGrammar
        except BaseException:
            llm.close()
            raise
        self._formatter, self._grammar_type, self._abort_cb = formatter, grammar_type, abort_cb
        self._llm = llm

    def close(self) -> None:
        """Stop a running generation and free the model. Safe to call two times."""
        self._closing.set()
        with self._lock, self._model_lock:
            llm, self._llm = self._llm, None
            self._formatter = None
            self._grammar_type = None
            if llm is not None:
                llm.close()

    def render(self, user_text: str) -> str:
        formatter = self._formatter
        if formatter is None:
            raise LlmError("the model is not loaded")
        return formatter(messages=[{"role": "user", "content": user_text}]).prompt

    @staticmethod
    def _tokens(llm: Any, prompt: str) -> list[int]:
        # The rendered prompt already holds the BOS text (decision 0003).
        return llm.tokenize(prompt.encode("utf-8"), add_bos=False, special=True)

    def count_tokens(self, prompt: str) -> int:
        with self._model_lock:
            llm = self._llm
            if llm is None:
                raise LlmError("the model is not loaded")
            return len(self._tokens(llm, prompt))

    async def generate(self, prompt: str, params: GenParams, cancel: CancelToken) -> AsyncIterator[str]:
        if self._llm is None:
            raise LlmError("the model is not loaded")
        loop = asyncio.get_running_loop()
        queue: asyncio.Queue[Any] = asyncio.Queue()
        stop = threading.Event()

        def put(item: Any) -> None:
            with contextlib.suppress(RuntimeError):  # the loop can be closed already
                loop.call_soon_threadsafe(queue.put_nowait, item)

        def work() -> None:
            try:
                with self._lock:
                    self._current_stop = stop
                    try:
                        self._run(prompt, params, cancel, stop, put)
                    finally:
                        self._current_stop = None
            except BaseException as e:  # noqa: BLE001 - hand every error to the loop
                if self._closing.is_set():
                    put(LlmError("the model is closed"))
                elif stop.is_set() or cancel.cancelled:
                    put(_DONE)  # an abort after a stop or a cancel is not an error
                else:
                    put(e)
            else:
                put(_DONE)

        threading.Thread(target=work, daemon=True, name="forenote-llm").start()
        try:
            while True:
                item = await queue.get()
                if item is _DONE:
                    return
                if isinstance(item, BaseException):
                    raise item
                yield item
        finally:
            stop.set()

    def _run(self, prompt: str, params: GenParams, cancel: CancelToken, stop: threading.Event, put: Any) -> None:
        """Run one generation. The caller holds self._lock."""
        if cancel.cancelled:
            stop.set()  # the abort callback reads only the stop event
        llm = self._llm
        if llm is None or self._closing.is_set():
            raise LlmError("the model is closed")
        tokens = self._tokens(llm, prompt)
        if len(tokens) + params.max_tokens > self.context_size:
            raise PromptTooLong(
                f"{len(tokens)} prompt tokens + {params.max_tokens} output tokens > context {self.context_size}"
            )
        grammar = None
        if params.json_schema is not None:
            grammar = self._grammar_type.from_json_schema(json.dumps(params.json_schema), verbose=False)
        for chunk in llm.create_completion(
            tokens,
            max_tokens=params.max_tokens,
            temperature=params.temperature,
            stream=True,
            grammar=grammar,
        ):
            if stop.is_set() or cancel.cancelled:
                break
            text = chunk["choices"][0]["text"]
            if text:
                put(text)
```

A cancel that comes during the prompt read must also abort it. The abort callback reads only `stop`, and `CancelToken.cancelled` is set on the loop thread. `collect()` reacts to the cancel at once and closes the stream, and the `finally` block of `generate` sets `stop`. That sets the abort for the worker. Do not read the `CancelToken` inside the callback.

`_should_abort` takes one argument because llama.cpp calls it with the `data` pointer.

The existing test `test_close_during_a_generation_is_not_an_attribute_error` uses a property subclass on `_llm` and the thread name `forenote-llm`.
```python
"""Transcript context for the notes job: line format, prefix, mode, chunks (spec B 4.1, 5.3, 5.4)."""

from __future__ import annotations

from typing import Any

from forenote.notes import prompts
from forenote.store.notes import Bullet

PREFIX_RESERVE = 2048  # room for one task and its output (spec 5.3)
CHUNK_TOKENS = 3000  # map-reduce chunk size (spec 5.4)
BULLET_LINES_TOKENS = 1500  # transcript lines in one map-reduce bullet prompt (spec 5.4)
WINDOW_BEFORE_MS = 180_000
WINDOW_AFTER_MS = 60_000

SPEAKER = {"me": "Me", "others": "Others"}


def clock(ms: int) -> str:
    s = max(0, ms) // 1000
    return f"{s // 60:02d}:{s % 60:02d}"


def format_line(line: dict[str, Any]) -> str:
    return f"[{clock(line['t_start_ms'])}] {SPEAKER[line['speaker']]}: {line['text']}\n"


def transcript_text(lines: list[dict[str, Any]]) -> str:
    return "".join(format_line(line) for line in lines)


def bullets_text(bullets: list[Bullet]) -> str:
    if not bullets:
        return prompts.NO_NOTES
    rows = []
    for number, b in enumerate(bullets, 1):
        when = f" [{clock(b.t_written_ms)}]" if b.t_written_ms is not None else ""
        rows.append(f"{number}.{when} {b.text}\n")
    return prompts.NOTES_TITLE + "".join(rows)


def build_prefix(lines: list[dict[str, Any]], bullets: list[Bullet]) -> str:
    """The shared prefix of all tasks: instructions, transcript, bullets (spec 5.3)."""
    return prompts.HEADER + prompts.TRANSCRIPT_TITLE + transcript_text(lines) + "\n" + bullets_text(bullets) + "\n"


def fits(gen: Any, user_text: str, reserve: int = PREFIX_RESERVE) -> bool:
    return gen.count_tokens(gen.render(user_text)) <= gen.context_size - reserve


def choose_mode(gen: Any, prefix: str) -> str:
    return "prefix" if fits(gen, prefix) else "map_reduce"


def window(t_ms: int) -> tuple[int, int]:
    return max(0, t_ms - WINDOW_BEFORE_MS), t_ms + WINDOW_AFTER_MS


def split_chunks(gen: Any, lines: list[dict[str, Any]], max_tokens: int = CHUNK_TOKENS) -> list[list[dict[str, Any]]]:
    """Cut the lines into chunks of up to max_tokens. A longer line is a chunk of its own."""
    chunks: list[list[dict[str, Any]]] = []
    current: list[dict[str, Any]] = []
    size = 0
    for line in lines:
        n = gen.count_tokens(format_line(line))
        if current and size + n > max_tokens:
            chunks.append(current)
            current, size = [], 0
        current.append(line)
        size += n
    if current:
        chunks.append(current)
    return chunks


def bullet_lines(
    gen: Any,
    lines: list[dict[str, Any]],
    t_written_ms: int | None,
    match_times: list[int],
    max_tokens: int = BULLET_LINES_TOKENS,
) -> list[dict[str, Any]]:
    """The lines for one bullet in map-reduce mode: the time window first, then the keyword matches.

    Stop at max_tokens. Return the lines in storage order.
    """
    candidates: list[dict[str, Any]] = []
    if t_written_ms is not None:
        start, end = window(t_written_ms)
        candidates += [line for line in lines if start <= line["t_start_ms"] <= end]
    times = set(match_times)
    candidates += [line for line in lines if line["t_start_ms"] in times]
    picked: dict[int, dict[str, Any]] = {}
    size = 0
    for line in candidates:
        if line["id"] in picked:
            continue
        n = gen.count_tokens(format_line(line))
        if size + n > max_tokens:
            break
        picked[line["id"]] = line
        size += n
    return sorted(picked.values(), key=lambda line: line["id"])
```

```python
"""Keyword search over the transcript of one meeting (spec B section 4.1)."""

from __future__ import annotations

import re
import sqlite3

MAX_MATCHES = 5  # spec 5.3

_WORD = re.compile(r"\w+")
_STOP = frozenset(
    "the and for with that this from have will are was were you your our not but can all any "
    "has had his her its they them then than there what when who how why".split()
)


def fts_query(text: str) -> str | None:
    """An FTS5 query that matches any word of text. Return None when no word is left."""
    words = []
    for word in _WORD.findall(text.lower()):
        if word in _STOP:
            continue
        if len(word) >= 3 or (len(word) >= 2 and word.isdigit()):
            words.append(word)
    if not words:
        return None
    return " OR ".join(f'"{w}"' for w in dict.fromkeys(words))


def keyword_times(conn: sqlite3.Connection, meeting_id: int, text: str, limit: int = MAX_MATCHES) -> list[int]:
    """Return the start times (ms) of the best matching lines of the meeting, in time order."""
    query = fts_query(text)
    if query is None:
        return []
    rows = conn.execute(
        "SELECT t.t_start_ms FROM transcript_fts f JOIN transcript_lines t ON t.id = f.rowid "
        "WHERE transcript_fts MATCH ? AND t.meeting_id = ? ORDER BY bm25(transcript_fts) LIMIT ?",
        (query, meeting_id, limit),
    ).fetchall()
    return sorted(int(r[0]) for r in rows)
```

`bm25()` ranks over all meetings, and the meeting filter applies after the join. With many meetings this reads more rows than necessary, but the result is correct. Do not optimize this now.

  - `async def enhance_notes(deps: NotesDeps, meeting_id: int, force: bool, cancel: CancelToken, report: Report) -> str`. It returns the mode. It raises `NotesError` ("The meeting has no transcript."), `JobCancelled` (a cancel, or the meeting is deleted), or the errors of the generator.
  - `class NotesError(Exception)`.
  - Events: `notes.delta` with `{"meeting_id", "part", "text"}` and `"bullet_id"` for `part == "bullet"`.

**Design decisions:**
- First-token limit (spec 8.1): the model reads the whole prompt before the first token. The limit is `max(STALL_S, prompt_tokens / 20 + 60)`. Decision 0003 measured 43 to 59 tokens/s for the prompt on one machine; 20 tokens/s is a floor for a slower laptop. Plan B3 (`bench llm`) can use a measured speed.
- Failed re-run (carry item "Failed re-run"): the job calls `NotesStore.start_output()` only when the summary step ends, right before `set_summary()`. A job that fails or is cancelled before that keeps the old summary and the old action items.
- A deleted meeting: before and after each generation, the job checks that the meeting exists. If it does not, the job raises `JobCancelled`. It stores nothing after that.
- Action items that do not parse as a list of `{owner, text}` give `[]` and a warning with no content (spec 8.1).
- An empty expansion (only white space) leaves `enhanced_text` as it is (spec 8.1: it stays NULL for a new bullet).
- Progress messages hold no user content: `"note 3"`, `"summary"`, `"action items"`.

```python
"""The notes job (spec B section 5)."""

from __future__ import annotations

import json
import logging
import sqlite3
from collections.abc import Callable
from dataclasses import dataclass
from typing import Any

from forenote.llm.base import STALL_S, GenParams, TextGenerator, collect, first_token_limit
from forenote.notes import context, prompts
from forenote.notes.search import keyword_times
from forenote.scheduler import CancelToken, JobCancelled, Report
from forenote.store.meetings import MeetingStore
from forenote.store.notes import Bullet, NotesStore

log = logging.getLogger(__name__)

BULLET_TOKENS = 200
SUMMARY_TOKENS = 500
ACTION_ITEMS_TOKENS = 500
MAP_TOKENS = 300
TEMPERATURE = 0.2
ALL_LINES = 1_000_000

Emit = Callable[[str, dict[str, Any]], None]


class NotesError(Exception):
    """The job cannot run for this meeting. The message is for the user."""


@dataclass
class NotesDeps:
    gen: TextGenerator
    conn: sqlite3.Connection
    emit: Emit
    stall_s: float = STALL_S


async def enhance_notes(deps: NotesDeps, meeting_id: int, force: bool, cancel: CancelToken, report: Report) -> str:
    """Write the notes of one meeting. Return the mode ("prefix" or "map_reduce")."""
    return await _Job(deps, meeting_id, force, cancel, report).run()


def parse_action_items(text: str) -> list[dict[str, Any]] | None:
    """Return the items, or None when the text is not a list of {owner, text}."""
    try:
        data = json.loads(text)
    except ValueError:
        return None
    if not isinstance(data, list):
        return None
    items = []
    for item in data:
        if not isinstance(item, dict) or not isinstance(item.get("text"), str):
            return None
        owner = item.get("owner")
        if owner is not None and not isinstance(owner, str):
            return None
        if item["text"].strip():
            items.append({"owner": (owner or "").strip() or None, "text": item["text"].strip()})
    return items


class _Job:
    def __init__(self, deps: NotesDeps, meeting_id: int, force: bool, cancel: CancelToken, report: Report):
        self.gen = deps.gen
        self.conn = deps.conn
        self.emit = deps.emit
        self.stall_s = deps.stall_s
        self.mid = meeting_id
        self.force = force
        self.cancel = cancel
        self.report = report
        self.meetings = MeetingStore(deps.conn)
        self.notes = NotesStore(deps.conn)
        self.steps_done = 0
        self.steps_total = 1

    def check(self) -> None:
        """Stop on a cancel, or when the meeting is gone (spec 8.1)."""
        self.cancel.check()
        if self.meetings.get(self.mid) is None:
            raise JobCancelled()

    def step_done(self, message: str) -> None:
        self.steps_done += 1
        self.report(message, self.steps_done / self.steps_total)

    async def generate(
        self, user_text: str, max_tokens: int, part: str | None, bullet_id: int | None = None, schema: dict | None = None
    ) -> str:
        self.check()
        prompt = self.gen.render(user_text)
        limit = first_token_limit(self.gen.count_tokens(prompt))

        def on_delta(text: str) -> None:
            if part is None:
                return
            params: dict[str, Any] = {"meeting_id": self.mid, "part": part, "text": text}
            if bullet_id is not None:
                params["bullet_id"] = bullet_id
            self.emit("notes.delta", params)

        params = GenParams(max_tokens=max_tokens, temperature=TEMPERATURE, json_schema=schema)
        text = await collect(self.gen, prompt, params, self.cancel, on_delta, self.stall_s, first_token_s=limit)
        self.check()
        return text.strip()

    async def run(self) -> str:
        self.check()
        lines = self.meetings.lines(self.mid, None, ALL_LINES)
        if not lines:
            raise NotesError("The meeting has no transcript.")
        bullets = self.notes.bullets(self.mid)
        todo = [(n, b) for n, b in enumerate(bullets, 1) if self.force or not b.enhanced_edited]
        prefix = context.build_prefix(lines, bullets)
        mode = context.choose_mode(self.gen, prefix)
        if mode == "prefix":
            await self._prefix_mode(prefix, todo)
        else:
            await self._map_reduce_mode(lines, bullets, todo)
        return mode

    def _times(self, b: Bullet) -> list[int]:
        return keyword_times(self.conn, self.mid, b.text)

    @staticmethod
    def _bullet_task(number: int, b: Bullet, times: list[int]) -> str:
        matches = [context.clock(t) for t in times]
        if b.t_written_ms is None:
            return prompts.bullet_task(number, b.text, None, None, matches)
        start, end = context.window(b.t_written_ms)
        return prompts.bullet_task(
            number, b.text, context.clock(b.t_written_ms), (context.clock(start), context.clock(end)), matches
        )

    async def _bullet(self, number: int, b: Bullet, user_text: str) -> None:
        text = await self.generate(user_text, BULLET_TOKENS, "bullet", b.id)
        if text:
            self.notes.set_generated(b.id, text, self.force)
        self.step_done(f"note {number}")

    async def _summary_and_items(self, base: str, mode: str) -> None:
        summary = await self.generate(base + prompts.SUMMARY_TASK, SUMMARY_TOKENS, "summary")
        # Replace the old result only now: a failure before this keeps it (carry item "Failed re-run").
        self.notes.start_output(self.mid, self.gen.model_id, mode)
        if summary:
            self.notes.set_summary(self.mid, summary)
        self.step_done("summary")
        raw = await self.generate(
            base + prompts.ACTION_ITEMS_TASK, ACTION_ITEMS_TOKENS, "action_items", schema=prompts.ACTION_ITEMS_SCHEMA
        )
        items = parse_action_items(raw)
        if items is None:
            log.warning("meeting %d: the action items did not parse; stored an empty list", self.mid)
            items = []
        self.notes.set_action_items(self.mid, items)
        self.step_done("action items")

    async def _prefix_mode(self, prefix: str, todo: list[tuple[int, Bullet]]) -> None:
        self.steps_total = len(todo) + 2
        for number, b in todo:
            await self._bullet(number, b, prefix + self._bullet_task(number, b, self._times(b)))
        await self._summary_and_items(prefix, "prefix")

    async def _map_reduce_mode(self, lines: list[dict[str, Any]], bullets: list[Bullet], todo: list[tuple[int, Bullet]]) -> None:
        raise NotesError("The transcript is too long for the language model.")  # Task 5 replaces this
```

**Interfaces:**

- Produces: `context.group_parts(gen, parts: list[str], task: str) -> list[list[str]]`. `enhance_notes()` returns `"map_reduce"` for a transcript that does not fit the prefix budget, and stores `mode = "map_reduce"`.

**Design (spec 5.4):**
1. Map: `split_chunks(gen, lines, context.CHUNK_TOKENS)`. For each chunk, the prompt is `HEADER + PARTS_TITLE + transcript_text(chunk) + "\n" + map_task(i, n)`, with `max_tokens = 300`. Map steps send no `notes.delta` (no part type fits).
2. Bullets: for each bullet to do, the prompt is `HEADER + PARTS_TITLE + transcript_text(bullet_lines(...)) + "\n" + bullets_text(bullets) + "\n" + bullet_task(...)`.
3. Reduce: `base = HEADER + REDUCE_TITLE + the chunk notes, one block for each part`. While `base + SUMMARY_TASK` does not fit (`context.fits`) and more than one part is left, combine the parts in groups (`group_parts` with `GROUP_TASK`), one generation per group (`max_tokens = 300`). Stop the loop when a round does not make fewer parts. Then write the summary and the action items from `base`, as in prefix mode.

Pass the module constants at call time (`context.CHUNK_TOKENS`, `context.BULLET_LINES_TOKENS`), not as default arguments, so that a test can lower them with `monkeypatch`.

```python
def group_parts(gen: Any, parts: list[str], task: str) -> list[list[str]]:
    """Put the parts in groups, in order. Each group fits one prompt, or holds one part only."""
    groups: list[list[str]] = []
    current: list[str] = []
    for part in parts:
        candidate = current + [part]
        text = prompts.HEADER + prompts.REDUCE_TITLE + "".join(p + "\n" for p in candidate) + task
        if current and not fits(gen, text):
            groups.append(current)
            current = [part]
        else:
            current = candidate
    if current:
        groups.append(current)
    return groups
```

```python
    async def _reduce(self, parts: list[str]) -> list[str]:
        """Combine the chunk notes in groups until the summary prompt fits (spec 5.4)."""
        while len(parts) > 1:
            base = prompts.HEADER + prompts.REDUCE_TITLE + "".join(p + "\n" for p in parts) + "\n"
            if context.fits(self.gen, base + prompts.SUMMARY_TASK):
                break
            groups = context.group_parts(self.gen, parts, prompts.GROUP_TASK)
            if len(groups) >= len(parts):
                break  # no group holds two parts: a further round does not help
            self.steps_total += len(groups)
            combined = []
            for group in groups:
                text = await self.generate(
                    prompts.HEADER + prompts.REDUCE_TITLE + "".join(p + "\n" for p in group) + prompts.GROUP_TASK,
                    MAP_TOKENS,
                    None,
                )
                combined.append(text)
                self.step_done("combine notes")
            parts = [p for p in combined if p]
        return parts
```

```python
"""RPC handlers for notes.* methods (spec B section 7.1)."""

from __future__ import annotations

import logging
from typing import Any

from forenote.rpc.protocol import APP_ERROR, RpcError

log = logging.getLogger(__name__)

NOTES_JOB = "notes.enhance"


class NotesHandlers:
    def _check_meeting(self, meeting_id: int) -> dict[str, Any]:
        m = self.meetings.get(meeting_id)
        if m is None:
            raise RpcError(APP_ERROR, "No such meeting.")
        return m

    def _recorder_time(self, meeting_id: int) -> int | None:
        """The recorder time if this meeting records now (spec 5.2)."""
        recorder = self._recorder
        if recorder is not None and recorder.meeting_id == meeting_id:
            return recorder.elapsed_ms()
        return None

    async def _notes_add_bullet(self, params: dict[str, Any]) -> dict[str, Any]:
        mid = params["meeting_id"]
        self._check_meeting(mid)
        bullet = self.notes.add_bullet(mid, params["text"], self._recorder_time(mid))
        return {"bullet": bullet.to_dict()}

    async def _notes_update_bullets(self, params: dict[str, Any]) -> dict[str, Any]:
        mid = params["meeting_id"]
        self._check_meeting(mid)
        items = [(b.get("id"), b["text"]) for b in params["bullets"]]
        ids = [i for i, _ in items if i is not None]
        if len(ids) != len(set(ids)):
            raise RpcError(APP_ERROR, "A bullet is twice in the list.")
        known = {b.id for b in self.notes.bullets(mid)}
        if any(i not in known for i in ids):
            raise RpcError(APP_ERROR, "No such bullet.")
        bullets = self.notes.replace_bullets(mid, items, self._recorder_time(mid))
        return {"bullets": [b.to_dict() for b in bullets]}

    async def _notes_get(self, params: dict[str, Any]) -> dict[str, Any]:
        mid = params["meeting_id"]
        self._check_meeting(mid)
        out = self.notes.output(mid) or {
            "summary": None, "action_items": None, "model": None, "mode": None, "created_at": None,
        }
        job = self.jobs.latest(NOTES_JOB, mid)
        return {
            "bullets": [b.to_dict() for b in self.notes.bullets(mid)],
            **out,
            "job": {"id": job["id"], "status": job["status"]} if job else None,
        }

    async def _notes_update_enhanced(self, params: dict[str, Any]) -> dict[str, Any]:
        if not self.notes.set_enhanced(params["bullet_id"], params["text"], edited=True):
            raise RpcError(APP_ERROR, "No such bullet.")
        return {}
```

**Behavior (spec 5.1, 5.6, 7.1, 8.1):**
- When a recording stops, the recorder asks `final_status(meeting_id)`. The engine answers `"processing"` when the meeting has transcript lines, the LLM of the tier is installed, and the engine does not stop. Otherwise `"done"`. The recorder stores this status and sends it in `meeting.state`. If the status is `processing`, the engine queues the notes job (priority NOTES, payload `{"meeting_id", "force": false}`).
- While a recording runs, the scheduler pauses the priority NOTES. A notes job that already runs continues (spec 5.1). When the recording ends, the engine resumes NOTES.
- When a notes job ends (done, failed, or cancelled, also a queued job that is cancelled), the engine sends `notes.done` and, if the meeting is `processing`, sets it to `done` and sends `meeting.state`. Do this in `_on_job`, because the scheduler calls the listener also for a queued job that it cancels.
- The engine loads one LLM instance at the first notes job (`run_in_daemon_thread(gen.load)`) and keeps it. When the tier or the model changes, it closes the old one. A load error fails the job with the text `"The language model cannot load ({ErrorType}). Try the low tier: it uses a smaller model."`, and the engine keeps no instance. After `GenerationStalled` or `MemoryError`, the engine drops the instance: it closes it in a plain daemon thread and does not wait for it.
- `Engine.stop()` closes the instance after the scheduler stops (wait up to 10 s).
- At engine start, `finish_processing()` sets all `processing` meetings to `done` (spec 4.2).

```python
    def _llm_entry(self) -> ModelEntry | None:
        return llm_for_tier(self.manifest, self.tier())

    def _llm_installed(self) -> bool:
        entry = self._llm_entry()
        return entry is not None and self.models.is_installed(entry)

    def _final_status(self, meeting_id: int) -> str:
        """The status of a meeting when its recording stops (spec 5.1)."""
        if self._closed:
            return "done"
        m = self.meetings.get(meeting_id)
        return "processing" if m and m["line_count"] > 0 and self._llm_installed() else "done"

    async def _notes_enhance(self, params: dict[str, Any]) -> dict[str, int]:
        mid = params["meeting_id"]
        m = self._check_meeting(mid)
        recorder = self._recorder
        if m["status"] == "recording" or (recorder is not None and recorder.meeting_id == mid):
            raise RpcError(APP_ERROR, "The meeting is still recording.")
        last = self.jobs.latest(NOTES_JOB, mid)
        if last is not None and last["status"] in ("pending", "running"):
            raise RpcError(APP_ERROR, "The notes are already in progress.")
        if not self._llm_installed():
            raise RpcError(APP_ERROR, MODEL_MISSING)
        if m["line_count"] == 0:
            raise RpcError(APP_ERROR, "The meeting has no transcript.")
        return {"job_id": self._queue_notes(mid, bool(params.get("force", False)))}

    def _queue_notes(self, meeting_id: int, force: bool) -> int:
        async def job(cancel: CancelToken, report: Report) -> None:
            gen = await self._notes_generator()
            deps = NotesDeps(gen, self.conn, self._emit_event, self.notes_stall_s)
            try:
                await enhance_notes(deps, meeting_id, force, cancel, report)
            except (GenerationStalled, MemoryError):
                self._drop_llm()  # the instance can be in a bad state (spec 8.1)
                raise

        return self.scheduler.submit(NOTES_JOB, Priority.NOTES, job, {"meeting_id": meeting_id, "force": force})

    async def _notes_generator(self):
        """The loaded LLM of the tier. Load it at the first use and keep it (spec 4.2)."""
        entry = self._llm_entry()
        if entry is None or not self.models.is_installed(entry):
            raise NotesError(MODEL_MISSING)
        tier = self.tier()
        key = (entry.id, tier)
        if self._llm is not None and self._llm_key == key:
            return self._llm
        self._drop_llm()
        path = Path(self.models.path(entry)) / entry.files[0].name
        gen = self.llm_factory(path, entry.id, CONTEXT_SIZE[tier], self.hardware.threads)
        try:
            await run_in_daemon_thread(gen.load)
        except Exception as e:  # noqa: BLE001 - out of memory, a broken file
            log.error("the language model cannot load: %s", type(e).__name__)
            raise NotesError(
                f"The language model cannot load ({type(e).__name__}). Try the low tier: it uses a smaller model."
            ) from None
        self._llm, self._llm_key = gen, key
        return gen

    def _drop_llm(self) -> None:
        """Forget the instance. Close it in a daemon thread: a hung model must not block the engine."""
        llm, self._llm, self._llm_key = self._llm, None, None
        if llm is not None:
            threading.Thread(target=llm.close, daemon=True, name="forenote-llm-close").start()

    def _notes_job_ended(self, job_id: int, status: str) -> None:
        """Send notes.done and end the processing status (spec 5.1)."""
        job = self.jobs.get(job_id)
        mid = job["payload"].get("meeting_id") if job else None
```

```python
def _notes_lines(meeting_id: int, n: dict[str, Any]) -> list[str]:
    rows: list[str] = []
    if n["summary"]:
        rows += ["Summary:", n["summary"], ""]
    if n["action_items"] is not None:
        rows.append("Action items:")
        rows += [f"- {i['owner'] or 'No owner'}: {i['text']}" for i in n["action_items"]] or ["- none"]
        rows.append("")
    if n["bullets"]:
        rows.append("Notes:")
        for b in n["bullets"]:
            when = f"[{_clock(b['t_written_ms'])}] " if b["t_written_ms"] is not None else ""
            rows.append(f"{b['position']}. {when}{b['text']}")
            if b["enhanced_text"]:
                rows.append(f"   {b['enhanced_text']}")
    if not n["summary"] and n["action_items"] is None and not any(b["enhanced_text"] for b in n["bullets"]):
        return [f"No notes yet. Run 'forenote-cli enhance {meeting_id}'."]
    return rows


def _bullet_text(b: dict[str, Any]) -> str:
    when = f" at {_clock(b['t_written_ms'])}" if b["t_written_ms"] is not None else ""

async def _read_bullets(client: Any, meeting_id: int, inp: Any, say: Any) -> None:
    """Add each typed line as a bullet (spec 7.3). Empty lines do nothing."""
    async for raw in inp:
        text = raw.strip()[:500]
        if not text:
            continue
        try:

        except RpcError as e:
            print(f"Error: {e.message}", file=sys.stderr, flush=True)
            continue
        say(_bullet_text(bullet))


async def _stdin_lines():
    """Yield the lines that the user types. A daemon thread reads stdin."""
    loop = asyncio.get_running_loop()
    queue: asyncio.Queue[str | None] = asyncio.Queue()

    def put(item: str | None) -> None:
        with contextlib.suppress(RuntimeError):  # the loop can be closed already
            loop.call_soon_threadsafe(queue.put_nowait, item)

    def read() -> None:
        for line in sys.stdin:
            put(line)
        put(None)

    threading.Thread(target=read, daemon=True, name="forenote-stdin").start()
    while (line := await queue.get()) is not None:
        yield line
```
